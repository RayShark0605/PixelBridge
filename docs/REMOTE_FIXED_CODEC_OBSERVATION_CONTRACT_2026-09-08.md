## 3. 简单归一化为何不是修复

令同一条边缘的黑白电平为`b,w`，`w>b`；原括区亮度为`v0,v1`，搜索步长为`h`，括区左位置为`x0`。原线性crossing为：

```text
t = ((b+w)/2 - v0) / (v1-v0)
x = x0 + h*t
```

若仅做`u=(v-b)/(w-b)`，以`u=1/2`求crossing，则：

```text
t' = (1/2 - (v0-b)/(w-b)) / ((v1-b)/(w-b) - (v0-b)/(w-b))
   = ((b+w)/2 - v0) / (v1-v0)
   = t
```

这个恒等式成立的条件是**相同b/w、相同括区与采样位置、相同线性插值**，且对比度和分母非零。实际浮点重排可能改变末位；这种差异不能被包装成新的观测支持或用于跨过质量门。

本轮以精确有理数核对所选6个历史样本、10次已完成迭代的480条边缘记录，两侧表达式全部相等。这是代数复核，不是新像素实验。若改用另一种黑白电平估计、采样窗口或非线性处理，已不属于上述简单归一化，需要自己的偏差/适用条件，不能以此恒等式证明或否定它。

## 4. 唯一审查的模板位置区间模型

只考虑一个统一模型表达，不轮换高斯/锐化/中值等参数矩阵：

```text
z_j = a + c * F_k(x_j - theta) + e_j
c > 0
```

- `z_j`：实际可观察的亮度采样，单位为亮度码值。
- `x_j`：物理坐标；`theta`为边缘位置，单位px。
- `F_k`：公开marker局部模板经过候选响应`k`后的采样预测。单边缘推导中可写成阶跃响应；实际2D块/邻接污染不能默认忽略。
- `a,c`：局部偏置和对比度，不自动等同于从有损像素测出的精确真实黑白值。
- `e_j`：预测、量化、颜色转换、局部模型失配与数值计算的总差异；不是仅最终8-bit舍入误差。

在**模型族覆盖实际输入**且已知有界`K,A,C,E`的条件下，定义可行集：

```text
Q(z) = {(theta,a,c,k): k in K, a in A, c in C,
        abs(z_j - a - c*F_k(x_j-theta)) <= E_j for every j}
I(z) = outer enclosure of projection_theta(Q(z))
```

未来若实现，应输出区间/多解/不可用原因，不将最小残差点直接当作正确位置。无可行解表示模型与输入不符；多个可行位置必须保留；有界求解未完成时返回不确定，不能把搜索中找到的最优点当作已排除其余解。插值及求解舍入还须由向外包围或独立误差项覆盖。

四marker的边缘区间可约束共享的`origin/scale`；但不能因为联合OLS残差小就忽略公共偏移。再将该区间约束与原准入、安全发布等规则衔接，需要单独的工程验证，本轮不定义或修改生产返回值。

### 4.1 未锚定响应的位置歧义

若模型允许平移响应，令`k_delta(t)=k(t+delta)`，则其阶跃响应满足：

```text
F_k_delta(u) = F_k(u+delta)
theta' = theta + delta
F_k_delta(x-theta') = F_k(x-theta)
```

同一亮度曲线便能同时解释成不同边缘位置。非负、积分为1或支持宽度有限，都不单独确定响应的原点；支持必须有独立位置锚定，或另有可证明的相位约束。

精确有理数示例验证了两个位置相差1px、响应中心相反移动1px的解释可以完全一致。**这是未锚定模型族的可辨识性反例，不是找到了两份固定x264输入生成同一真实码流，更不是已发现生产false-accept。** 任意响应平移也不是已证实的H.264可达行为。

### 4.2 误差预算不能由同一拟合自证

若没有独立的`E_j`限制，任意候选位置都可把剩余差异定义为`e_j`。用当前最小残差或当前样本最大残差设置E，只证明训练实例可被容纳，不能证明真实位置一定在所得区间内。

8-bit输出只提供有限值域；即便使用0..255的平凡差值上界，也通常无法产生有判别力的位置区间。`0.5 LSB`至多涉及某个明确量化步骤，不能直接覆盖整个有损codec和颜色转换链。

即使已知正误差界，也不自动得到精确点位置：若包含对比度c的完整亮度预测`m(theta)=a+c*F_k(x-theta)`关于theta为L-Lipschitz，则满足`L*abs(delta)<=E`的小位移可由误差项吸收。它说明区间可能有正宽度，而不是证明所有实际编码输入都不可区分。

### 4.3 不把区间存在等同于安全吸附

若企图用“连续真实几何完整覆盖”证明规范尺寸ROI中的吸附安全，单轴约束为：

```text
scale >= 1; origin >= 0; origin + scale*C <= C
=> origin = 0 and scale = 1
```

因此，某个位置区间**包含**canonical解，不等于像素支持排除真实位移/裁切。G1B四个1px位移反例已说明仅看已有残差预算不够。

这不是给生产增加一个更严格的“所有连续真实几何都必须唯一”准入规则。原sharp-point/离散采样支持有自身语义，不能用上述连续模糊模型取代；像素逐字节等价的历史裁切回填仍保持既有分类。此处仅审查区间模型能否为所提吸附提供充分证据。
