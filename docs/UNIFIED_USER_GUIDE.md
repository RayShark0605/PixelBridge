# PixelBridge Unified — 双端 GUI 使用指南

当前界面属于 G22 Windows x64 本地发布候选；打包和新版实屏验收状态以
[G22 工作记录](UNIFIED_G22_GUI_RELEASE.md) 为准。本文不把旧实验 CLI 当作日常操作流程。

## 1. 启动与大小单位

双击 `PixelBridgeEncoder.exe` 或 `PixelBridgeDecoder.exe` 打开对应界面，不附带黑色控制台窗口。
两端均只有主页面和“高级选项”两个 Tab；首次使用一般不需要修改高级设置。

界面的 `KB`、`MB`、`GB` 与 Windows 文件大小的含义一致，均按 1024 进位；`1 KB/s = 1024 bytes/s`。
单文件允许空文件以及不超过 **500 GB** 的文件（536,870,912,000 bytes；技术文档写作 500 GiB）。
支持范围内，接收任何大小的文件都不再要求额外确认；磁盘空间和文件安全检查仍然执行。

## 2. Encoder：选择文件，然后循环发送

1. 先将 Encoder 主窗口放到希望用于传输的显示器。
2. 在“传输”页选择一个文件。刷新率默认 15 Hz，可在开始前设为 1..60 Hz。
3. 点击“开始传输”。准备过程中会读取并冻结 Session，随后在当前显示器全屏显示数据流。
4. 规范数据画布为 1920×1080 物理像素，1:1 居中，剩余屏幕使用中性背景，不拉伸数据画布。
5. 数据流持续循环，不按时间、轮数或 Decoder 完成消息自动停止。Encoder 持有键盘焦点时按 **Esc** 停止传输。

从准备开始到停止完成，文件和刷新率不能修改。请保持源文件不变；源文件变化、显示器失效等错误会安全停止。
Esc 不是系统全局快捷键：若切换到了别的软件，应先切回 Encoder 再按 Esc，避免影响其他软件的操作。

“高级选项”可设置 Session 缓存目录、导出诊断报告，或显式删除当前 Session。
正常停止会保留 Session；只有用户主动选择删除时才确认删除，**这与已取消的文件大小确认无关**。

## 3. Decoder：指定目录和屏幕区域，然后接收

1. 选择已有且可写的文件保存目录。
2. 在显示器列表中明确选择包含数据画面的屏幕。
3. 点击“整屏”，或点击“框选区域…”选择包含完整数据画面的 ROI。
   框选层只覆盖刚才选中的显示器，不会覆盖其他显示器；取消框选保留之前的有效选区。
4. 点击“开始接收”；同一个按钮会变成“停止接收”。
5. 保持完整数据画面可见。没有有效画面、画面丢失或暂时不再刷新时，Decoder 持续等待后续画面并保留已验证进度。

主页面只展示三项进度：

- **当前进度**：已验证原始数据的百分比；最终文件复验完成前不会显示 100%。
- **恢复速度**：按已验证原始字节估计的 KB/s，不是发送 FPS 或收到的数据包总量。
- **剩余时间**：根据真实恢复进度估算；尚无足够样本或停滞时显示“估算中”，不虚构倒计时。

点击“停止接收”会安全停止并保留断点。再次接收同一 Session、使用同一目录时，会先验证可恢复状态再继续。
整文件摘要、安全发布和最终重新打开复验全部通过后，接收自动停止，界面保留 **100% / 已完成**。
不会自动弹出完成对话框或打开目录；如需查看文件，可在高级页点击“打开完成文件所在目录”。

不会静默覆盖已有最终文件；目标冲突、磁盘不足或不安全文件名会报告错误，而不是绕过检查继续写入。
ROI 使用物理像素且必须在单个所选显示器内；改变显示器布局后，应刷新显示器列表并重新选择区域。

“高级选项”允许精确填写 ROI 左/上/右/下边界（右/下不包含）以及界面状态刷新间隔。
状态刷新默认 250 ms，只影响文字更新，不限制捕获或恢复速度；捕获后端保持自动选择。

## 4. 开发者诊断与日志（非日常 GUI 操作）

原命令行诊断仍可用，参数/退出码保持原约定。Windows GUI 子系统不会自动创建控制台：
从已有终端运行诊断时连接该终端；重定向的标准输入、输出、错误分别保留。

交互式 PowerShell 对裸调用 GUI EXE 不保证等待。需要同步输出和立即读取退出码时，使用管道：

```powershell
& .\PixelBridgeEncoder.exe --version | Out-Host
$LASTEXITCODE

$identity = & .\PixelBridgeDecoder.exe --build-identity | ConvertFrom-Json
$identity

# 完整保留日志并显式等待（diagnosticArgs 为所需诊断参数数组）
$process = Start-Process -FilePath .\PixelBridgeDecoder.exe -ArgumentList $diagnosticArgs -WindowStyle Hidden -Wait -PassThru -RedirectStandardOutput .\decoder.stdout.log -RedirectStandardError .\decoder.stderr.log
$process.ExitCode
```

不要通过历史实验参数改变 Unified 的 Profile、FEC 或文件验证规则来“提高成功率”。需要排查时，优先导出高级页中的诊断报告。
项目自身许可证、签名及公开发布决定不由本指南代替；本地候选不代表已公开发布。
