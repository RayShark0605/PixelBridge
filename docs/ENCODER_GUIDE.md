# PixelBridge v1.0 — Encoder 操作说明

**简体中文** | [English](ENCODER_GUIDE.en.md)

## 必须先读

1. **建议 Decoder 先开始接收，再开启 Encoder 发送。**
2. **Decoder 接收大文件时，“已接收大小”可能暂时不涨：补齐纠删修复块、等待轮播、写盘和校验都可能造成正常等待，此时不要暂停。** 明确错误、捕获中断或持续没有新有效数据需要检查，并非所有停滞都正常。
3. Encoder 不会收到完成 ACK；以 Decoder 显示的成功完成为准，再手动停止发送。

## 安装与环境

- 本包用于存有源文件的远程 Windows x64 电脑。完整解压到新目录，运行 `PixelBridgeEncoder.exe`，不要只复制 EXE，不要覆盖旧版本目录。
- 运行环境要求 Windows 10 1903 或更新版本 / Windows 11、可用的 D3D11 图形与桌面会话。Qt 平台基线并不等同于本项目已逐个验证所有 Windows/驱动版本。
- 已附 Qt 与 MSVC 运行库，不需要安装开发工具、Python 或 PBBridge。系统提供 ICU、D3DCompiler_47 和 Windows API；不支持缺少这些系统组件的精简系统。不要从非官方网站补 DLL。
- 使用现有远控视频画面即可。不需要调整网络或远控设置，不使用剪贴板、共享目录或隐藏网络通道传送文件内容。
- 单文件当前准入上限 **500 GiB**。分段流式处理不要求整文件驻留内存，但需要足够缓存/输出磁盘空间；该上限不是已实测最大文件声明。

## 模式如何选

两端选择同一模式，不能混用。

Encoder GUI 新安装、缺失或非法 `g22/carrier` 偏好时默认选择 PAM4（索引 2）；合法已保存索引继续原样恢复。Standard 仍保留为索引 0 的兼容模式，CLI/core 默认与 GUI 默认分开。Decoder 端必须选择同一模式和 Profile 身份。

| 模式 | 特点 | 建议 |
| --- | --- | --- |
| 标准 | 兼容保留的彩色形状/色度路线 | 已验证该路线的环境或兼容旧流程 |
| 灰阶高速 | 避开色度失真，使用多级灰阶；名称不是普遍速度保证 | 对照/兼容选项，不能假设一定比 PAM4 快 |
| PAM4 | 四级亮度与结构化单元，固定 1920×1080 源码面 | **1080P 非本机场景优先试用** |
| PAM4 Wide | PAM4 的独立更宽布局，固定 2560×1440 源码面 | 源桌面可容纳该尺寸时使用，例如 1440P/1600P |

PAM4 Wide 不能压缩成 1080P 后当作相同模式使用。PAM4 家族发送端使用未旋转、最大 3840×2160 的目标屏。可保留静态边缘；以数据质量和稳定性优先，不必铺满窗口。这里的分辨率是物理像素，不是 DPI 逻辑尺寸。

新环境可从 **25 Hz** 开始验证；1–60 Hz 是设置范围，而不是越高越快。远控内部刷新、缩放与编码可能使过高发送频率反而降低有效吞吐。留存特定环境的大文件最高平均结果约 **279 KB/s**（1 KB = 1024 B），不是所有模式、分辨率或电脑的保证。

## 操作步骤

1. 在需要文件的电脑完整解压 Decoder 包，选择输出目录、接收屏幕/区域和模式，**先开始接收**。
2. 本端打开 Encoder，选择源文件、相同模式和目标显示器，设置发送频率。
3. 确认远控画面完整显示目标码面，然后开始发送。初始化会先准备/校验源数据，并非一点击就立即进入稳定发送。
4. 保持源文件不变、程序运行和电脑不休眠；不要删除会话缓存。不要改变分辨率/DPI/显示模式，不要遮住码面。
5. Decoder 显示成功完成后，再停止 Encoder。轮播次数、显示 FPS、网络流量不能替代完成确认。

## 中断、日志与排查

- 正常停止优先于强制结束。恢复原 Session 时保留原始文件及原缓存；不要把改过的文件或另一会话当作断点续传。
- 高级选项可打开日志目录。默认位置为 `%LOCALAPPDATA%\PixelBridge\Logs\Encoder`。
- `run-<id>.events.jsonl` 为时间序列，通常每 2 秒采样；正常结束尝试写 `run-<id>.summary.json`。强杀/断电可能没有最终报告。
- 分析慢速请同时保存两端同一 Session 的日志，并记录文件大小、模式、发送 Hz、分辨率和远控环境。自动日志有限额和轮换，需要的记录请及时另存。
- 日志不包含 payload/截图，但可能包含文件名、路径及机器信息，公开前先检查。
