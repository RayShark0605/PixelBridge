## 2. 为什么只约束合法几何并不足够

对单个轴，设规范画布长度为 C，ROI 长度也为 C。拟议的完整画布约束为：

```text
scale >= 1
origin >= 0
origin + scale * C <= C
```

这些条件的唯一可行解是 `origin=0, scale=1`。因此，在规范尺寸 ROI 上，所谓“受约束拟合”可能事实上退化为强制 canonical 几何。**数学上可行的几何，不等于从像素证明了该几何。**

必须另外检验这个解得到什么样的观测支持。本轮检验的具体假设是：四个 marker 验证通过、全部 48 条边缘可测、完整画布合法，并且所有边缘对该解的最大残差不超过已有 `maximumGeometryResidualPixels=1.25`，是否足以构成准入判据。

答案是否定的，且不需要放宽任何数值就能给出反例。

### 2.1 四个真实位移反例

复用 G1 的四个 `crop-pad-opposite-*` 样例：从一侧去掉一列/行，再在另一侧补原背景，产生可观测的 1 像素内容位移。它们不属于主人已确认的逐字节等价回填。

| 方向 | 原 `FitAxis` 的 `(originX, originY)` | 原拟合最大残差 | 强制 `(0,0,1,1)` 后最大边缘残差 | 原 CPU blocks |
| --- | --- | ---: | ---: | ---: |
| 左 | `(-1,0)` | 0 | 1 | 0 |
| 右 | `(1,0)` | 0 | 1 | 0 |
| 上 | `(0,-1)` | 0 | 1 | 0 |
| 下 | `(0,1)` | 0 | 1 | 0 |

四个 marker 均通过原角色/对比度/quiet 验证，48 条边缘均可读且满足原 sharp endpoint 条件。**四个样例都满足上述残差谓词，因为 `1 <= 1.25`，但原几何准入正确拒绝它们。**

所以不能把 `1.25 px` 从“给定拟合的边缘一致性预算”直接解释成“可以纠正多少真实几何位移的预算”。同向移动所有边缘时，拟合残差甚至可以保持为零；它不提供绝对几何误差上限。

本轮没有把这个不充分的谓词连接到 Bootstrap 或数据恢复。上述是**几何判据反例**，不是已实现替代 Decoder 的最终 false-accept 漏洞，也不是假定其余检查都能通过。

### 2.2 最小正例的精确读数

复用 `one-marker-edge-plus-one`：生产 1920×1080 raster，仅将 `(20,47)` 的 B/G/R 各加 1，不改变实际几何。

- 48 条边缘中 47 条满足原 sharp 条件，只有一条不满足。
- 该条 crossing 对规范位置的偏差：`0.0013054830287195784 px`。
- 邻接采样值相对 marker 黑白水平的最大偏差：`0.5`，这里是亮度单位，不是像素。
- 原第一轮拟合和 G1 记录完全相同：

```text
originX = 0.00011337968305724644
originY = 0
scaleX = 0.9999999385577532
scaleY = 1
markerResidualPixels = 0.00119333219059925
```

这个正例支持“单像素光度扰动导致几何估计偏差”的因果链，但不支持无条件吸附、删除那条边缘、给未知有损录像指定新容差或跳过原覆盖门。

### 2.3 录像读数及不能得出的结论

只重放 `30Hz_Remote.mkv` 的前 36 个观测，PTS 0..583，time base 1/1000，使用原 pinned FFmpeg 8.1.1 输入契约。

- 每个观测均完整测到 48 条边缘，共 1728 条。
- **1728 条中没有一条满足原 exact sharp crossing + endpoint 条件。**
- 相对 canonical 假设的最大 crossing 偏差：`0.008087127640465042 px`。
- 这 36 个几何假设都能落入 1.25 残差预算，然而上面的四个位移负例也能，故不能据此接纳。
- 原路径仍为 **16 个观测、240 blocks**；前缀像素摘要、五字段几何、接纳/擦除状态和全部逐块摘要与封存 G1 精确一致。

这些读数不是已知真实几何下的统计误差界；不能从观察到的最大值选 `0.01 px` 当安全阈值。`0.005 px` 仍只是现有迭代收敛量；半像素 sharp point support 也不能未经论证直接搬到非 sharp 有损边缘。

结论仅淘汰“完整画布 + 全边缘已有残差预算”这一充分性主张，**没有证明所有鲁棒估计或几何修复都不可能**。
